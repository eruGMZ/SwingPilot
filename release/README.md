# release/ — Artefactos de Release

## Propósito

Este directorio almacena los artefactos de release de SwingPilot.

## Condiciones para una release

La liberación de cualquier versión requiere:
1. Cumplimiento de todos los criterios de aceptación del alcance de la release.
2. Evidencia de pruebas unitarias, integración, aceptación, regresión y seguridad.
3. Gate G6 (Seguridad) en estado PASS.
4. Gate G7 (Aprobación de release) en estado PASS — **requiere aprobación humana explícita**.
5. Documentación actualizada.
6. Versión registrada en este directorio.

## Restricción crítica

La aprobación de una release **no autoriza automáticamente operaciones financieras reales**.

Toda activación de operaciones reales requiere autorización humana adicional y explícita.
