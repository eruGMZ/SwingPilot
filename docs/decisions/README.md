# docs/decisions/ — Decisiones Humanas Aprobadas

## Propósito

Este directorio almacena decisiones formales del propietario del proyecto que tienen autoridad máxima sobre el desarrollo de SwingPilot.

## Jerarquía

Las decisiones aquí depositadas prevalecen sobre la documentación original, los outputs de extracción y el contrato técnico.

## Formato recomendado para decisiones

```
DEC-NNN_descripcion-breve.md

Fecha: YYYY-MM-DD
Decisión: descripción de la decisión
Motivación: por qué se tomó
Impacto: qué áreas del sistema afecta
Firmado: propietario del proyecto
```
