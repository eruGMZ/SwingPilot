# docs/context/ — Documentación Original de SwingPilot

## Propósito

Este directorio es el repositorio de la **documentación original de SwingPilot**, la fuente de verdad para FASE 1.

## Instrucciones para el propietario del proyecto

Deposite aquí los documentos originales de SwingPilot antes de autorizar FASE 1. Los documentos pueden incluir:
- Especificaciones del sistema.
- Decisiones de diseño.
- Documentos de estrategia.
- Manuales operativos.
- Cualquier documento que defina el comportamiento esperado de SwingPilot.

## Restricciones (para todos los agentes)

- **Solo lectura** para extractores y verificador.
- **No modificar** ningún documento de este directorio.
- **No eliminar** ningún documento de este directorio.
- **No crear** documentos sintéticos en este directorio.
