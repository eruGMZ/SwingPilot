# docs/policies/ — Políticas Obligatorias

## Propósito

Este directorio almacena las políticas que definen restricciones no negociables para el desarrollo y operación de SwingPilot.

## Tipos de políticas esperadas

- Políticas de gestión de riesgo.
- Políticas de aislamiento Train/OOS.
- Políticas de prevención de look-ahead bias.
- Políticas de seguridad de credenciales.
- Políticas de operación (paper trading vs. real).
- Cualquier restricción que no pueda violarse por decisión técnica.

## Restricción

Las políticas aquí registradas no pueden omitirse ni excepcionarse por decisión unilateral del agente.

Cualquier excepción a una política requiere autorización humana explícita y se gestiona mediante `harness/change_requests/`.
